# "Informed dataset selection with APS"- Reproduced
This is the code for the experiment from the paper ("Informed dataset selection with APS"- Reproduced) by  Abdelrahman Al-Taslaq, reproducing the original paper (Informed Dataset Selection with ‘Algorithm Performance Spaces’ (ACM RecSys 2024)) by Joeran Beel, Lukas Wegmeth, Lien Michiels, and Steffen Schulz.
